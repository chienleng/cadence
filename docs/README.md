# Cadence documentation

Cadence runs on your computer and reads the projects you register. The app, your source
repositories and your private workspace records each have a separate home.

## Start here

1. [Set up your workspace](setup-with-ai.md) — install Cadence, register projects and connect your
   coding agent, or configure the files yourself.
2. [Use the dashboard](product.md) — find projects, read status, compare work and follow record links.
3. [Run everyday commands](commands.md) — validate data, refresh GitHub counts and load agent context.
4. [Back up your records](privacy.md) — understand what stays local and what a public demo includes.
